# Edinburgh Aless

Guida personale mobile-first di Edimburgo.

## Pubblicazione con GitHub Pages

Carica `index.html`, `.nojekyll` e `README.md` nella radice del branch `main` della
repository `alessalessaless/edinburgh-aless` (non caricare il file ZIP).
In Settings > Pages scegli: Deploy from a branch > main > /(root) > Save.

URL atteso: https://alessalessaless.github.io/edinburgh-aless/

Questa versione pubblica non include le immagini e i numeri delle tessere
fedeltà, né il riferimento a un indirizzo personale.

Il sito è statico: non richiede dipendenze né una build. I preferiti vengono
salvati localmente nel browser. Le informazioni commerciali, gli orari e alcune
schede devono essere ancora verificati prima di considerare la guida definitiva.
